Cyberpunk

My résumé as the menu of a Cyberpunk game: implants, a skill tree, a project journal and a 3D career map.

Why I built it

I love the cyberpunk aesthetic, and Cyberpunk 2077's menu already works like a résumé: the body has parts, each part gets implants and skills grow on a tree.

The experience I wanted to create

Stepping into a game menu: the boot sequence, the neon, the glitch and the UI sounds, except the character is me and every implant shows how I work.

01The original idea

Every implant, a way of working

I started from the game's Cyberware screen: a glass body where each part is an area of my work, and every implant has an in-game name and a real meaning.

My Debug Sandevistan is how I track down bugs fast. My Pixel-Perfect Optics stand for my eye for every detail on screen. You can also put together a build for each role (Back end, Front end, or Product & AI) and see which implants each one uses.

02How it grew

From one screen to a full menu

  1. Start

    A 3D body, then images

    The first body was a 3D glass figure. It was hard to read, so I went back to images, with a close-up of each part and smooth transitions between them.

  2. Skills

    A real skill tree

    My tech stack became a skill tree in the style of the game's 2.0 update: hold to unlock.

  3. Projects and contact

    Journal and messages

    Projects laid out like the game's Journal, and a Contact screen where the message arrives with the sound of typing.

  4. Story

    A career map

    A 3D city with a building for each company, and the character running between them with the anime's Sandevistan effect.

  5. Entry

    Optics boot

    An access screen with glitches, an alarm sound and a button to boot up the neural network.

03Technical evolution

How the menu works

  1. 01

    No build step, straight in the browser

    Plain HTML, CSS and JavaScript, with three.js loaded through an import map. Each screen is a module and nothing needs compiling to run.

  2. 02

    An entire city in 3D

    The Story map builds neighborhoods, buildings, a river, plazas of different shapes and an elevated highway with traffic. The route links the company buildings in career order.

  3. 03

    Character and Sandevistan

    A VRM character runs the route with a camera that follows the curves, and the Sandevistan effect leaves a trail of colored afterimages, just like in the anime.

  4. 04

    Game UI in CSS

    Angled cuts, glitch transitions between screens and crossfading body close-ups, aligned to the position of each part.

  5. 05

    UI sound

    Web Audio so hover sounds never lag or cut each other off, a different ambient track per screen with fades, and synthesized keystrokes on the Contact screen.
